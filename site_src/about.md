# About

**Land & Field Research** is an independent, open, MIT-licensed encyclopedia of Earth's land surface. It is a static website generated from Markdown articles and JSON catalogs by a Python build script, and hosted on GitHub Pages.

## How the content is built

- **Articles** are written from authoritative sources (FAO, UNCCD, IPCC, IMD, WGMS, ICAR, NCERT, USGS and peer-reviewed papers) and list their sources at the end.
- **Catalog entries** carry curated facts. Each entry page also loads, live in your browser: a **photo** from Wikimedia Commons, the **full Wikipedia article** split into collapsible sections, **sounds** from Wikimedia Commons where they exist, and a list of the **most-cited and newest research papers** from OpenAlex.
- **Statistics** are rendered as animated SVG charts with their sources.

## Accuracy

Numbers are rounded and dated; live figures change. If you find an error, please open an issue on GitHub.
